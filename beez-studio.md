# Beez Studio

**Architectural Consultancy & Construction Firm — Dhaka, Bangladesh**

> "Where Architecture Becomes Art."

Beez Studio is a multidisciplinary design and construction consultancy established in 2007, based in Dhanmondi, Dhaka. The studio delivers end-to-end architectural, interior, and infrastructure solutions across Bangladesh.

## Features

- **Portfolio Download** — Visitors can download the studio's full portfolio as a file.
- **Smooth Animations** — Page transitions and section reveals powered by Framer Motion.
- **Responsive Design** — Fully optimized for mobile and desktop.
- **Dynamic Routing** — Single-page application using `wouter` for client-side navigation.
